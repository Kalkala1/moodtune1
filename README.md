1. MoodTune, aplikasi ini tentang mood tracker. Jadi ini kayak ngebantu user buat bikin diary gitu, bikin jurnal, nyatet tentang perasaannya, terus juga
   bisa liat perubahan mood dari history dan statistik.
2. fitur:
  - Mood Check In
  - Mood Match
  - Mood Journal
  - Mood History
  - Mood Statistic
  - Daily Mood Card
  - Mood Streak
  - Profile & Settings
3. teknologi:
  - Kotlin
  - Jetpack Compose
  - SensorManager
  - SQLite
  arsitektur: MVVM
4. Sensor:
  - Accelerometer (motion sensor)
  - Light sensor (environment sensor)
